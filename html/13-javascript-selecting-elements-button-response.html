13. JavaScript: Selecting Elements + Button Response

JavaScript Basics

Select Page Elements and Respond to a Button

Before JavaScript can change a page element, it needs a reference to that element. document.getElementById("practiceMessage") asks the DOM for the element whose id is practiceMessage. Saving the result in a clearly named constant gives later code an easy way to use that element. IDs should be unique within the page so the connection is predictable.

Once you have the element reference, textContent can replace its visible text. The first example on this screen changes the paragraph immediately when the script runs. The second step connects that change to the button event. Together, selection and events form a basic interaction pattern: find the elements, listen for the user action, then update the page.

When this pattern fails, check the connection points. Does the HTML contain the exact id that JavaScript requests? Did you spell getElementById correctly? Is the event listener attached to the button rather than the paragraph? Small naming mismatches are common beginner errors and usually easier to find when the variables have descriptive names.

Key ideas

  • Element IDs provide stable hooks for beginner JavaScript.
  • Store selected elements in descriptive variables.
  • textContent changes the text inside an element.
  • Check exact spelling when the script cannot find an element.
