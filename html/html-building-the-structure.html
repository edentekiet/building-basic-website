HTML: The Structure of a Webpage

HTML stands for HyperText Markup Language. It organizes the content of a webpage using elements called tags. For example, HTML tags can create headings, paragraphs, images, links, and buttons.

<br><!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>
<body>
    <h1>Welcome to My Webpage</h1>
    <p>This is my first paragraph.</p>
    <button>Click Me</button>
</body>
</html>

The <h1> element creates the main heading, the <p> element creates a paragraph, and the <button> element creates a button. At this point, the button will appear on the page, but it will not perform an action until JavaScript is added later.
