5. HTML: Basic Document Structure

HTML Basics

The Basic HTML Document Structure

A complete HTML page follows a specific document structure. Before there are any major tags, you must put "<!DOCTYPE html>". This tells the browser to use modern HTML. This is a tag. Last submodule, you learnt all about tags. Unlike the previous tag structure, this is a standalone tag, which don't require a closing tag. Some other standalone tags include:

  • <br> - Placed in paragraphs or other large text clumps in order to start a new line.
  • <hr> - Makes a horizontal line to break sections up.
  • <img> - Allows you to place an image in your document.

Earlier, we discussed the html tag. The <html> tag wraps the whole document. Inside it, the <head> stores information about the page, like <link> tags and the <title>. An snippet of an HTML head should look like this:

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
    <link rel="icon" type="png" href="my_favicon.png" />
<head>

The <title> inside the head names the browser tab. The character-set meta element helps the browser interpret text correctly, and the viewport meta element helps the page scale on phones and tablets. The <link> provides a favicon, which is an image / icon next to the title. These lines are not visually exciting, but they are part of a dependable starting template. Notice also that most HTML elements have an opening tag and a closing tag, and nested elements are indented so their relationships are easier to read.

HTML describes meaning before appearance. At this stage, the page may look plain because CSS has not been added. That is okay. Your first goal is a correctly organized document that the browser can understand. Styling comes after the structure is in place. HTML can be seen as the skeleton of the document, meaning that as long as it is there, there is something the browser can recognize.

The <body> element stores what's meant to be visible. For example, paragraphs and headers are put there. They are also found in this nested format. You may take a look below in the provided code editor.

Key ideas

  • Put page information in <head>.
  • Put visible page content in <body>.
  • Nest tags carefully and keep indentation consistent.

HTML Basics

Some Extra Information

These activities should give you a grasp on how HTML should be structured. You may practice more using the code editor above or the code editor on the next page.

One more important thing to note is a few things about HTML that have been either seen or will be seen from now on.

  • Elements and tags can have attributes. It typically looks like <tag attribute="setting"> ... </tag>. One example of this is in an <img> tag, you can set a properties like src which is the image's file name and alt that gives a description. Here is an example of this in action: <img scr="Chart.png" alt="A picture of a chart">
  • HTML does have comments. Any text between '<!--' and '-->' will be seen as a comment and not rendered by the Browser.
  • One more important thing is the anchor tag. You can put the anchor tag around something to make it a link to something else. This can be anything, from images, to paragraphs, to divs. An example of this is: <a href="MyOtherPage.html"><p>Click this to go to my other page!</p></a>.
