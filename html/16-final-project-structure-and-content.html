Combining the Technologies

Build the Final Webpage: Structure and Content

The final build begins with the HTML foundation. Your goal is not to invent a completely new project; it is to assemble the same pieces you have practiced into a coherent page. The starter structure includes a header, navigation, About section, practice card, resources section, image, and footer. Before touching CSS or JavaScript, read the page from top to bottom and confirm that the content order makes sense without styling.

Make the page your own while preserving its learning requirements. Change the site heading and introductory sentence. Rewrite the About paragraph. Add or replace one resource link. Keep the image's alternative text meaningful, maintain a visible label on the interactive button, and preserve the IDs practiceMessage and tipButton because the JavaScript on the next screen will depend on them.

This is also a good accessibility check. Headings should describe the page hierarchy, link text should be understandable without relying on “click here,” and navigation should use real links. A well-structured page should remain understandable even if every CSS rule is temporarily removed. That is a useful test of whether HTML is carrying the right responsibility.

Key ideas

  • Build a logical reading order before styling.
  • Keep interactive IDs stable when JavaScript depends on them.
  • Use descriptive link text and meaningful image alternatives.
  • Make sure the page still makes sense without CSS.

Your task

Personalize the final HTML structure and content. Do not change the CSS or JavaScript yet. Run the page and verify the complete content flow.

Quick check: Why should the final page make sense even without CSS?

Because HTML should provide meaningful structure and content independently of presentation.
