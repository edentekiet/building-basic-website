The Basics of HTML

First let's start off with what HTML is. HTML stands for HyperText Markup Language. This may seem like random words, but it does have meaning behind it. HyperText, the 'HT', simply refers to text that has links, references, and other extra aspects that regular text may not have. Markup Language, the 'ML', is a shorthand way of saying that the language itself can change and give structure to the HyperText. 

HTML is mostly composed of tags. Tags is what gives structure and order to the document, and allows you to give special meaning to each element. Tags are defined like the following: "<tag> </tag>". Before we get into structure, let us go over basic tags and what they do.

Tags typically have an opening and closing of them. An opening is simply the name encapsulated with a less than and greater than symbol like so: "<tag>". Tags are then closed in a similar fashion, but with a slash before the tag's name, like so: "</tag>". This is useful as you can put content in between the start and closing tag.

Key ideas

  • Understand what HTML stands for.
  • Understand what HTML means.
  • Understand what a tag is in HTML and how it is formatted.

The Basic Tags of HTML

Here are some basic tags and what they do:

<p> - Stands for "paragraph," allows you to put simple, regular text. Example: "<p>This is paragraph text!</p>"

<h1> - Stands for "header," with the 1 signifying it's the largest type of header. Numbers range from 1-6, with a smaller number leading to a smaller header. Example: "<h2>This Is a Header!</h2>"

<title> - Stands for "title," titles your webpage, and is typically found at the head / top of your document. Example: "<title>This is a title</title>"

<head>, <body> - Separate, but main sections of your document, with different parts going into each. More information on the next sub module.

<div> - Stands for "division", allows for grouping and advanced structure.

<html> - Main section, all other tags should be placed within this one, everything within is defined as part of the document, though, more will be discussed during the next section.

Key ideas

  • Understand how the given tag structure applies to HTML.
  • Remember some of the basic tags in HTML.
  • Know how to use said basic tags of HTML.
