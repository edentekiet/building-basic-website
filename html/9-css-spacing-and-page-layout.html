9. CSS: Spacing and Page Layout

CSS Basics

Add Spacing and Page Layout

Spacing and layout turn a collection of elements into an organized page. Margin creates space outside an element, while padding creates space inside its border. The box-sizing property can make widths easier to predict. In the project, generous padding keeps text away from card edges, while margins separate one section from another. These choices create visual grouping without adding extra HTML.

Layout also needs to respond to available space. A max-width keeps long text from stretching across an extremely wide monitor, while automatic left and right margins center the content. Images can use width: 100% and height: auto so they scale with their container. A media query can reduce padding on a narrow screen. Responsive design does not require a completely different mobile page; it adapts the same content.

The CSS below also adds rounded corners and a subtle shadow to the content sections. Those details are optional decoration, but the spacing and responsive width directly support usability. Try not to solve layout with repeated
elements or spaces in HTML. Use CSS because spacing is a presentation decision.

Key ideas

  • Margin = outside space; padding = inside space.
  • Use max-width to keep reading lines comfortable.
  • Make images flexible instead of forcing a large fixed width.
  • Use media queries for targeted narrow-screen adjustments.

CSS Basics

More on Page Layout and Spacing

Another thing that can be used is using a flexbox. By applying 'flex' to display, then by applying a 'flex direction,' you can then style it by using things like "justify-content" and "align-items", which can be set to center to automatically center things. Justify content goes by major axis and aligning goes by the minor axis, which is set by the flex direction.

Another way is by setting margin to auto on its sides. When margin is given two values, it applies the first value is applied to the top and bottom, while the second value is applied to the left and right. For example, 'margin: 0px auto;' sets the top and bottom to nothing, but automatically setting the left and right to center it. Do note, that the 'auto' keyword does different things to different items, make sure to search what it does in certain contexts or test it out to see what it does.

Additionally, when you get more advanced, you can use media queries to set special CSS rules for when things get certain sizes.

Key ideas

  • Know how to use margins and padding to your pages benefit.
  • Remember to know how to style your content.
