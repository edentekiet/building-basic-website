8. CSS: Colors and Fonts

CSS Basics

Add Colors and Fonts

Last section, the basics of CSS was covered. Now, it's time to talk about the colors and fonts that CSS can set. These texts can be paragraphs, headers, or even applied to the parent of a text element that it can then apply to. Here is a list of some basic things you can change for a text that can be set by CSS.

color: Can add color to a text, by either giving any color value.
font-family: Changes the font of a text.
font-size: Changes the size of a font given a value.
font-style: Can give a font a style, like italics.
font-weight: Can bold a font given a value from 100-1000, with a higher value being bolder.
text-decoration: Can add decor like an underline or strikethrough.

That's generally it, but a few extra tips:

  • A color value can be given by things like a hex value ('#FF0000'), an rgb ('rgb(255, 0, 0)'), an hsl ('hsl(0, 100%, 50%)'), or just by name ('red').
  • The font-family property can be given a chain of fonts separated by commas, so if the first one fails to be loaded, it will load the next one in line. Make sure to use web-safe fonts, or fonts that most computers can recognize and has the files for!
  • The font-weight property can also be given a name value as well, like 'bold'.

Key ideas

  • Use font size and line height to support readability.
  • Ensure that your text is proper when styled.

CSS Basics

Add Colors and Fonts

Color and typography create visual identity, but their first job is readability. A small, consistent palette usually produces a stronger design than many unrelated colors. In this project, a dark neutral, teal accent, white surface, and light background create clear visual roles.

Contrast matters. Text must be easy to distinguish from its background, and links should remain recognizable. Avoid using color as the only signal for an important state. The example navigation links are white and bold against a dark header, while ordinary links use a teal color against white. Font size and line height also help learners scan longer explanations without crowding the page.

CSS lets you change these choices without altering the document's meaning. The <h1> remains the primary heading whether it is 32 or 52 pixels tall. This is one reason you should choose HTML elements for structure and CSS for appearance. As you edit, compare the result with the original and ask whether your new combination is easier or harder to read.

Key ideas

  • Use a small, purposeful color palette.
  • Maintain strong text/background contrast.
  • Use font size and line height to support readability.
  • Do not choose an HTML element merely for its default appearance.
