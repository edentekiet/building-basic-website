2. What You Will Learn + Pre-Check

Introduction

Objectives, the Three-Language Connection, and Pre-Check

A browser combines HTML, CSS, and JavaScript into one experience, but each language has a different responsibility. HTML describes what is on the page and how the content is organized. CSS describes how that content should look and how it should be arranged. JavaScript adds behavior, such as changing text after a visitor selects a button. Keeping these roles clear will help you decide where a change belongs when you build or debug a page.

By the end of the module, you should be able to identify the purpose of all three technologies, create the basic structure of a webpage with HTML, apply CSS to change appearance and layout, add one simple JavaScript interaction, and explain how the three pieces work together. The goal is a practical foundation, not memorization of every tag, property, or programming feature.

The short pre-check below is not graded. It simply helps you notice what you already know. If a question feels unfamiliar, that is expected; each answer will be covered later. After the pre-check, you will meet the embedded code editor and begin with the structural layer: HTML.

Key ideas

  • HTML = structure and meaning.
  • CSS = presentation and layout.
  • JavaScript = behavior and interaction.
  • The browser combines all three into the page the learner sees.
