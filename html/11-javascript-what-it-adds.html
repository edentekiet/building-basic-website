11. JavaScript: What It Adds

JavaScript Basics

What JavaScript Adds to the Page

While you've learnt HTML and CSS, or the base and style of a page, there is one more piece. Interactability, which belongs to JavaScript. JavaScript is a programming language which can give your website a bit more flare. For example, remember classes from earlier?

JavaScript can change the class of things, and by extension, the style, which applies immediately. Here's an example of that in action!

document.getElementById("elementId").classList.remove("classA");
document.getElementById("elementId").classList.add("classB");

This code does a lot, so allow it to be broken down. First 'document' refers to the document the script is called from. Next, 'getElementById' is a function that given a valid Id, it will pull that element in the code. Finally, the 'classList' part access that element's class list and removes, then adds different classes via their respective functions. It also could have been written as so:

let myElement = document.getElementById("elementId");
myElement.classList.remove("classA");
myElement.classList.add("classB");

This time, it uses the "let" variable to assign that element to a variable called "myElement," then using the variable to access its class list and change it there.

Key ideas

  • JavaScript can change the behaviors of a page.

Great! Let's try another example. This is a for loop. Reading the top of it, it counts from 0 to 9, since it starts at 0 and runs for any number below 10, but then counts up by 1 for each run.

let number = 0;
for (let count = 0; count < 10; count++) {
    number = number + count;
}
console.log(number);

What does this log out? @@45@@

Splendid job! One more example should do the trick. This time it works with an if-statement, which only runs if the condition given is true. If not, it runs whatever comes in the 'else' part.

let value = 17;
if (value - 16 < 5) {
    console.log("This number is smaller than 21.");
} else {
    console.log("This number is greater than 20.");
}

JavaScript Basics

What JavaScript Adds to the Page

The webpage already has structure and visual design, but it behaves mostly like a document. JavaScript adds the ability to respond after the page loads. It can react to a click, read information from a form, change text, add or remove a CSS class, or perform calculations. This module uses one small interaction so you can understand the connection without turning the project into a large programming exercise.

JavaScript works with values and instructions. A const declaration can store a reference that will not be reassigned, while let can store a value that needs to change later. You will not need advanced data structures here. The important idea is that JavaScript can locate an HTML element through the browser's Document Object Model, commonly called the DOM, and then read or change that element.

The project will add a practice card containing a paragraph and button. HTML will create those elements, CSS will style them, and JavaScript will change the paragraph after the button is selected. The behavior is intentionally simple because the learning objective is to understand the relationship among the technologies.

Key ideas

  • JavaScript adds behavior after the page loads.
  • The DOM is the browser's representation of the HTML page.
  • JavaScript can select an element and change its content.
  • Keep beginner interactions small enough to explain clearly.
