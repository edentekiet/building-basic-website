7. CSS: Introduction to Styles and Connetions

CSS Basics

An Introduction to Styles

From the previous sections, it can be seen on how HTML can set up a page. However, these setups typically lack colors, layout, and styles. That's because styling is the job of CSS, which stands for Cascading Style Sheet. The reason it is called this is because the page is a sheet composed of many style rules that 'cascade' in a way, with broad rules being overtaken by more specific rules.

In this submodule, you will learn some basic CSS rules, properties, and values, and then show how to connect to HTML. More advanced items will come in the following pages / submodules. First though, let's go over how a CSS should look like.

The following is an example of how CSS is written:

* {
    color: green;
}
p {
    color: blue;
    font-family: Arial;
    font-size: 12px;
}
.className {
    border: solid 1px red;
    display: box;
}
#idName {
    color: black;
    font-size: 20px;
}
h1 {
    color: pink !important;
}

That's an example of how CSS interacts with HTML. In the above example, it sets the color of all things like text green, then it makes all paragraph items blue, Arial, and 12px in font size. It then styles all elements with the class 'className' to have red border and be a box. Afterwards, it then styles an element with the id "idName". Finally, it declares something a rule as important.

For now, the rule of thumb is that the important flag is the most specific, and will take the most priority, then ids, then classes, then general items, then finally, with the lowest priority being Universal / General Rules.

Below will be more properties and values, however, they should be obvious based off the name of them alone. In addition, some of them will be things you've seen from the example above.

CSS has a priority list in which certain style rules take priority over the other. For example, it is well know that @@!important Flagged@@ styles have the most importance. On the other end of things, @@Universal@@ styles have the least priority.

The thing with the second most priority is @@Inline@@ styles, which can be found in the HTML document instead of the CSS.

Below that are styles dictated by @@ID@@, then styles dictated by @@Class@@. Finally, that leaves the style with the second lowest priority, which are style tailored for @@General Item@@s.
