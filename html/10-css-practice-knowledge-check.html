CSS Basics

CSS Practice, Before-and-After, and Knowledge Check

This CSS checkpoint asks you to transform the same HTML without rewriting its content. First, use Reset and look at the unstyled version mentally: the information is present, but the hierarchy relies mostly on default browser styles. Then run the provided stylesheet. Color, spacing, width, typography, and card treatment make the same information easier to scan. This before-and-after comparison shows why CSS is a separate layer rather than a replacement for HTML.

For guided practice, make three deliberate changes: choose a new accent color, adjust the section spacing, and change one typography rule. Avoid changing every value. A focused redesign makes it easier to explain what each property did. Check the page at a narrow browser width before you finish so your choices do not create horizontal scrolling or unreadable text.

The knowledge check reviews selectors, the stylesheet connection, spacing, and responsive design. If a CSS rule seems to have no effect, first verify that its selector matches the intended HTML and that the property name and value are valid. Debugging the connection is usually faster than randomly changing several rules.

Key ideas

  • CSS changes presentation without changing the underlying information.
  • Focused changes are easier to test than a complete redesign at once.
  • Responsive behavior should be checked at more than one width.
  • When a rule fails, verify the selector before rewriting the page.

Your task

Complete the three CSS changes, compare with Reset, then answer the four questions.
