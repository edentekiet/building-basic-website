Building a Basic Webpage

1. Welcome: See What You Will Build

Introduction

Welcome: See What You Will Build

Welcome to Basics in Webpage Making. This module is designed for beginners who are comfortable using a computer but have little or no experience creating webpages. Instead of treating HTML, CSS, and JavaScript as three disconnected subjects, you will use them to build one small webpage from beginning to end. Each section adds a new layer to the same project so you can see exactly what each technology contributes.

The finished page below is your destination. HTML will provide the heading, navigation, sections, links, image, button, and text. CSS will improve the colors, spacing, typography, and layout. JavaScript will make the practice button respond to a click. You do not need to install programming software or use a command line. When an activity includes the embedded editor, you can change the starter code and view the result directly in your browser.

Work through the screens in order the first time. Read the explanation, inspect the example, and then complete the short activity. When you experiment with code, change one thing at a time and look at the output before making another change. This makes it easier to understand cause and effect and easier to recover when a typo causes unexpected behavior.

Key ideas

  • One continuous webpage grows throughout the module.
  • Practice happens directly in the browser.
  • Knowledge checks provide immediate feedback.
  • The final activity combines structure, style, and interaction.

Your task

Preview the completed webpage. Notice its structure, visual styling, and the button that changes the message. You will build these layers step by step.

Quick check: What is the main project you will complete?

One small working webpage that combines HTML structure, CSS styling, and a JavaScript interaction.
